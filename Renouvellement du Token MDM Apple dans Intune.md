# Téléchargement du Token :
- Aller sur Apple Business Manager.
- En suite dans Appareils/Devices
- Cliquez dans "Service de Gestion"
- Allez dans le "Services de gestion des appareils" correspondant.
- Cliquez sur les (...) et sélectionnez "Télécharger le Jeton"

# Dans Intune :
- Une fois le jeton téléchargé.
- Se connecter a Intune.
- Aller dans "Devices"
- Puis dans "MacOs"
- Allez dans la section "enrollment", puis dans "Enrollment program tokens"
- Cliquez sur "Renew Token", Uploadez le token précédemment téléchargé.
  Celui-ci est directement validé pour une période d'un an et fait une Synchro
  avec l'Apple Business Account et remonte les appareils qui n'étaient pas forcément sync.
